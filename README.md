# Neural Network Framework from Scratch

A modular deep learning framework implemented from scratch using Python and NumPy. This project was developed to understand the fundamental principles of neural networks, backpropagation, and convolutional architectures without relying on high-level deep learning libraries.

## Features

### Core Components

* Modular neural network architecture
* Forward and backward propagation
* Parameter management
* Training and inference pipelines

### Layers

* Fully Connected Layer
* Convolution Layer
* Pooling Layer
* Flatten Layer

### Activation Functions

* ReLU
* Softmax

### Optimization

* Stochastic Gradient Descent (SGD)
* Learning rate management

### Loss Functions

* Cross Entropy Loss
