# Neural Network Framework from Scratch

A modular neural network framework implemented from scratch using Python and NumPy.

## Features

- Fully Connected Layer
- ReLU Activation Function
- Softmax Layer
- Loss Functions
- Gradient-Based Optimization
- Forward and Backward Propagation

## Project Structure

Layers/
Optimization/
NeuralNetwork.py

## Technologies

- Python
- NumPy
